# hellmo.de

A static live wallpaper wall at [hellmo.de](https://hellmo.de) that renders a mosaic of album covers from [last.fm/user/nichbar](https://www.last.fm/user/nichbar), led by the most recent listen, alongside a minimal corner HUD linking to [github.com/nichbar](https://www.github.com/nichbar).

The site is built with vanilla HTML, CSS, and JavaScript, serving a static snapshot (`data/lastfm.json`) refreshed every six hours by a scheduled GitHub Actions workflow.
